# Ortofoto DLC - Tile Server

Tiles XYZ (Slippy Map) generados desde ortofoto del proyecto DLC, captura del 21/04/2026.

## Uso en Azure Maps (Power BI)

URL pattern para configurar como Tile Layer:
```
https://[TU_USUARIO].github.io/[NOMBRE_REPO]/{z}/{x}/{y}.png
```
